Wonder 音频分离

从音频中分离人声与伴奏，为音乐练习和伴奏制作提供清晰、可访问的操作体验。

0.2.2 · 构建 16 · 免费测试版

下载与安装

适用于 Apple 芯片 Mac（M1 或更新），需要 macOS 14 或更新版本。不支持 Intel Mac。

免费下载 Wonder 音频分离（DMG）

  1. 下载并打开 DMG 安装盘。
  2. 将安装盘里的“Wonder 音频分离.app”复制到访达的“应用程序”文件夹。
  3. 从“应用程序”打开 Wonder 音频分离，选择音频并开始处理。

已安装 0.2.0 或更新版本，可在应用内按 Command+Shift+U 检查、下载并安装更新。手动替换应用前，请先正常退出旧版。

音频分离与无障碍操作

  • 内置卡拉 OK 模型，首次打开自动准备，无需另装 Python。
  • 创建任务时可选择保存伴奏、主唱或两者；按模型记住选择，重新打开后继续使用。
  • 默认卡拉 OK 同时保存伴奏和主唱，伴奏目标是保留和声。分离效果随歌曲而异。
  • 任务列表支持删除草稿、清空已结束记录和清理空草稿，保留原歌曲与处理结果。
  • 支持 Apple 芯片的 GPU 加速。
  • 可以按需要启用 TTA 处理；启用后处理时间会增加。
  • 支持键盘操作与 VoiceOver，便于选择文件、调整设置和了解处理状态。
