无障碍文档编辑器 · 支持

无障碍文档编辑器是iPhone本地文档工具，提供文库、文字与表格编辑、PDF阅读与受支持表单填写，以及按格式可用的导出操作。支持VoiceOver和显示调整。

使用帮助

  1. 从“文件”选择文档导入文库，或新建文档。
  2. 选择适合该格式的阅读或编辑功能。Excel编辑区上方的“确定”提交当前格，“取消”放弃本次输入；回车用于换行。
  3. 使用保存或导出，选择目标格式，再通过系统分享保存到“文件”或交给其他应用。

格式与边界

格式转换不保证任意复杂排版无损。PDF正文编辑生成独立Word副本；扫描页原样显示，不做OCR。EPUB以章节文字方式编辑。加密、签名或不支持的复杂文档可能只读。请保留原件并在重要使用前核对导出结果。
