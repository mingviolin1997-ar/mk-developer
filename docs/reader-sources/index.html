书源配置下载

把配置保存到 iPhone，再用小铭读书打开。不需要注册，也不需要手动填写网站地址。

下载配置文件

适用于小铭读书构建14及以后版本。文件包含书海阁、速读谷两个网站的地址和解析模板，不包含书籍正文。

下载书源配置（JSON）

点击会下载文件，不会自动完成应用内导入。下载后按下面三步操作。

在 iPhone 上导入

  1. 用 Safari 打开本页，点击“下载书源配置”。如出现下载确认，选择“下载”。
  2. 打开 iPhone 的“文件”应用，在“下载项”找到“小铭读书书源配置.json”。通过共享菜单选择“小铭读书”。
  3. 如果共享菜单没有小铭读书，打开应用的“设置 → 书源管理与导入 → 从文件导入书源”，选择刚才下载的文件。听到“导入成功”后即可搜索。

使用旁白时，下载链接、步骤标题和应用内导入按钮均有文字名称。也可以把下载的 JSON 文件直接发给朋友。

下载或导入遇到问题

网页显示一段代码，没有下载

这是 JSON 配置内容。使用 Safari 的共享菜单保存到“文件”，保留 .json 后缀，再从小铭读书中导入。

书源已经存在

重复导入相同配置不会新增重复项。同类型的不同配置会提示冲突；先在书源管理移除旧配置，再导入。已有书架、进度和已下载章节会保留。

网络访问不稳定

此页和配置文件从同一域名提供，不需要访问 GitHub 的下载页面。不同地区网络仍可能影响访问；可让朋友直接发送 JSON 文件，以离线方式导入。导入成功不代表第三方书籍网站一定可访问。

支持哪些配置格式

当前文件使用小铭读书 JSON 第1版，适配两种 HTML 模板，不是安卓阅读等软件的通用规则文件，也不会执行脚本。
