小铭读书使用说明

你可以导入自己有权阅读的书籍文件，也可以自行取得书源配置并导入。此页面只说明操作方法和格式支持，不提供或推荐书源。

导入书籍文件

  1. 将书籍保存在 iPhone 的“文件”应用中。
  2. 打开小铭读书，进入“书架”，选择“导入书籍”，再选取文件。
  3. 等待导入预览，核对书名、目录和正文后完成导入。复杂排版或受保护的文件可能无法完整解析；请留意应用给出的错误提示。

也可以在“文件”应用里使用系统共享菜单，选择小铭读书打开受支持的文件。

导入你自行取得的书源

书源是描述网站结构的配置，不是书籍正文或内容使用许可。请自行确认配置来源可信，并遵守内容提供者的访问条件。

从文件导入

  1. 将 JSON 配置文件保存到 iPhone 的“文件”应用。
  2. 在小铭读书打开“设置 → 书源管理与导入 → 从文件导入书源”，选取该文件。
  3. 查看应用给出的导入结果和不支持项。导入后可在书源管理中启用或关闭配置。

从链接导入

  1. 复制你自行取得的 HTTPS 配置文件链接。
  2. 在“设置 → 书源管理与导入”中选择添加链接，粘贴地址并选择“下载并导入”。
  3. 核对导入结果；不能访问、格式不兼容或需要登录的配置，应按应用提示处理。

导入配置不会替你注册第三方账号、取得会员资格或保证每个网站与作品都可访问。

目前支持的格式

书籍文件：TXT、EPUB、PDF、DOCX、Markdown（.md、.markdown）、非加密 MOBI，以及包含受支持书籍文件的 ZIP。ZIP 的处理仍受内部文件格式和大小限制。旧版 Word .doc 暂不支持，请先转换为 DOCX 或 TXT。

书源配置：小铭读书 JSON 配置，以及部分“阅读 2/3”规则 JSON。并非所有第三方规则都兼容；实际能否导入，以应用中的预览和错误提示为准。支持从本地 JSON 文件或 HTTPS 文件链接导入。

带密码、DRM、损坏或超出应用处理上限的文件，可能无法导入；某些复杂排版的显示与目录仍可能需要核对。
