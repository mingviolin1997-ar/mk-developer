小铭读书使用说明

这个个人网站介绍小铭读书的用法，并提供书源文件导入。你可以用自己的文件和配置阅读；应用会员不包含第三方服务的会员资格。

书源导入

请先安装小铭读书。点击导入按钮后，软件会下载所选文件；在预览页确认导入即可使用。

小铭书源 · 免费

完全免费，供日常看书使用，无需购买第三方会员。

导入小铭书源下载小铭书源文件
复制小铭书源链接https://dev.mk-musician.com/reader-sources/sources-v1.json

需自行向大灰狼购买会员，并使用自己的账号密码登录。此第三方书源无法免费使用，小铭读书会员不包含大灰狼会员。

点击导入大灰狼书源下载大灰狼书源文件

开始阅读

  1. 打开书架，选择“导入书籍”，从 iPhone“文件”中选择 TXT、EPUB、PDF、DOCX 或 Markdown。软件自动识别格式与目录；扫描 PDF 需要更多处理时间。
  2. 点开书籍后默认不朗读。双击“播放”开始，再次双击暂停；旁白双指双击也可以控制播放。
  3. 打开目录会定位到当前章节附近。可以搜索章节并切换正序、倒序。
  4. 从搜索或发现打开新书，可以预览目录、立即试读，或加入书架阅读。试读进度保存在阅读历史中。

播放与下载操作

以下操作适用于新版应用。

  • 播放按钮：双击播放/暂停，双击并按住打开“播放控制”。
  • 在播放控制中选择每句、每段或约15秒、30秒、1分钟跳转。播放按钮上滑回到已读内容，下滑前往后续内容。秒数由文字朗读时长估算。
  • 定时和“记住并重复定时”也在播放控制中，选择完成后收起。
  • 书架书籍的旁白操作中选择“下载整本为 TXT”；未完成会显示已下载与总章节数。下载完成后优先读取本地章节。
  • 书架顶部“本地书籍”可阅读和通过 iOS 共享菜单分享 TXT。只分享你有权分享的内容。
  • 设置→界面与显示，可调整字体、字号、明暗模式及中间两个标签的顺序。

常见问题

点击导入没有打开软件

需要42号及以后版本。也可以点击下载JSON文件，在 Safari 下载列表或“文件”中找到它，通过系统共享菜单选择小铭读书；或在应用设置→书源管理与导入→从文件导入书源选择文件。

如何手动复制链接

上面的每个地址均独立成段。复制整行，在小铭读书设置→书源管理与导入中粘贴，选择“下载并导入”，检查预览后确认。

提示已有不同配置

应用会保护已有配置。先查看已有书源；确需更换时，移除旧配置后重新导入。移除书源不会自动删除书架与阅读进度。

下载整本中途停止

已保存的章节会保留，可再次选择下载继续。保持应用前台最可靠；iOS 在后台可能暂停任务，播放音频也不能保证系统无限执行下载。未完成的书不会作为完整TXT导出。

大陆地区打不开怎么办

本页和配置文件同域提供，不依赖 GitHub 原始文件域名；但不能保证所有地区和运营商都可访问。可以请朋友直接发送JSON文件离线导入。
