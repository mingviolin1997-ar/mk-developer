登记我的设备

1. 把设备信息发给小铭

有 Mac：获取 iPhone 的 UDID
  1. 用数据线连接 iPhone 和 Mac，手机提示时点“信任”。
  2. 打开 Mac 的“访达”，在左侧选择你的 iPhone。
  3. 点击手机名称下方的设备信息，切换到显示 UDID。
  4. 在 UDID 上点右键并复制。需要的是 UDID，不是序列号或 IMEI。
没有 Mac 怎么办？

先联系小铭安排手机端登记。目前此页尚不提供自动获取 UDID 的描述文件。

把 UDID 和昵称直接发给小铭即可，也可以在下面整理好再复制。这里不会自动提交信息。

粘贴从访达复制的完整 UDID。

信息只在当前页面整理，不上传、不保存。无需提供 Apple ID、密码或付款。

2. 等通知，再回来安装

小铭把你的设备加入测试名单，并重新签好安装包后，会通知你。请在已登记的 iPhone 上用 Safari打开本页，找到自己昵称的标题，再选择要安装的 App。

如果显示“无法安装”，先确认登记的是当前这台手机；新加入的手机需要包含它的新测试包。若系统提示开启开发者模式，按系统提示操作。

请说明：哪个 App、手机型号、iOS 版本、刚才做了什么，以及遇到的问题。使用旁白时，也请告诉我们哪个按钮或提示不好操作。

用邮件反馈，或直接通过聊天发给小铭。
