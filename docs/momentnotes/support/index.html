小铭随记 MomentNotes · 支持

面向日常灵感、课堂与会议的录音笔记工具，提供清晰的视觉界面，并支持动态字体及VoiceOver操作。

开始使用

  1. 允许麦克风，开始录音；可暂停、结束并回听。
  2. 在兼容设备上转写，并整理摘要、翻译和事项。AI结果请结合原文核对。
  3. 使用分类、文件夹和旗标整理记录，按需要选择分享或导出。

会员与试用

录音、回听、阅读和导出已有内容免费。Plus提供新转写、AI摘要、翻译及自动事项提取。符合Apple资格的月订阅提供三天免费试用，购买确认页显示后续当地月价。只有确认订阅后才会按Apple规则续费；可在Apple账户管理或取消。应用设置提供恢复购买与官方优惠码兑换。

使用限制

识别、翻译和AI能力取决于设备、系统及语言资源。复杂摘要可能遗漏信息；提醒受通知权限、系统设置和专注模式影响。操作按钮需要兼容设备和快捷操作配置。应用不提供电话或其他App系统音频录制。
