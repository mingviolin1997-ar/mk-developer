Wonder Reader

A free Mac reader designed for accessible reading, with text-to-speech, OCR, and optional local AI translation and summaries.

0.1.8 · Build 44 · Free full version

Download and install

For Apple silicon Macs (M1 or later), running macOS 14 or later. Intel Macs are not supported.

Download Wonder Reader free (ZIP, about 48.4 MB)

  1. Download and unzip the file.
  2. Drag Wonder Reader.app into Applications.
  3. Open the app to start reading.

The app is Developer ID signed, notarized by Apple, and includes a stapled notarization ticket. No account or UDID registration is required.

No subscription or paid unlock is required. AI model downloads are optional and separate from the app download.

Installation instructions and keyboard shortcuts

Read first; add models when you need them

Ordinary reading, system text-to-speech, and Apple OCR work without downloading an AI model. Navigate the table of contents, add bookmarks, and return to your saved reading position.

The original text is read-only. Processing results are kept separately, so you can refer back to the source when checking a translation or summary.

Optional AI translation, summaries, and model-based recognition use downloaded models locally on your Mac. Choose Low, Mid, High, or Advanced in Settings → Models; download, enable, or delete models there. Low is about 867 MB; actual download sizes are shown in the app.

Internet access is needed to download models. You do not need Python, Homebrew, or a manually configured model runtime.

What is new in build 44

PDF Reading view improves text-and-image presentation, rotated images and source-page mapping. A page overview supplements graphics that are not separated individually. Press Command-3 again in the original-text area to check the original PDF layout. Source files remain read-only.

Select the current image and press Command-Shift-Z for OCR. The result is saved below that image and retained after reopening. Page and whole-document processing results remain in Command-4. Menus, shortcut help and the nine interface-language guides have been updated.

Build 44 introduces signed in-app update checks, including a manual Check for Updates command. You choose whether to download and install an offered update. Build 42 users must install this version manually once. The full cross-version replacement and restart workflow remains unverified.

Bookmarks and independent notes remain available: Command-B adds a bookmark, and Command-5 opens the list for editing and TXT or Markdown export. The app download does not include model weights.

Current limitations

Complex PDF clipping, multi-column reading order and table semantics are not comprehensively validated. OCR can contain errors, and AI translation and summaries need comparison with the original. Current-image translation, summaries and all model combinations have not been fully tested.

Cross-book and cancellation races, long-term human VoiceOver use, cross-device and braille behavior, clean-Mac installation and full automatic upgrades still have outstanding acceptance work. The previously reported intermittent close-book problem remains open.
