旁白Plus平台版隐私说明

更新日期：2026年11月15日。本页对应尚未公开发行的旁白Plus平台版。

本地处理

平台版在设备上处理朗读文字、方案和规则，不向开发者服务器上传屏幕文字或合成音频。系统声音由 iOS 提供和管理。平台版可导入系统声音引用包，以及与应用内置引擎兼容的模型数据包；安装包不预装第三方声音模型。

文件与模型凭据

你主动选择的语音包、规则包和方案保存在应用的共享容器中，供应用及其语音扩展使用。应用只接受支持的数据格式，不执行包内程序。模型凭据单独保存在此设备的钥匙串中，不写入语音包或诊断日志。

下载时的网络连接

在网站或文件服务下载文件时，该服务可能接收 IP 地址等连接信息，适用其自身政策。在应用内粘贴 HTTPS 链接并开始下载语音包时，应用会连接你选择的网址；该网站会收到 IP 地址和链接中的信息。

下载请求不附带语音方案、模型凭据或朗读内容。应用不会在后台定期查询这些下载网站；下载完成后仍需你检查并保存。

诊断日志

你可以启用、导出和清除诊断日志。只有另外开启“记录朗读内容”才会记录相应文字，这些文字可能包含私人信息。请在分享前检查。应用不会自动上传日志；你主动发送给开发者的反馈及附件会用于处理该问题，如需删除已发送的反馈，可联系下方邮箱。

购买与兑换

当前平台候选尚未开放收费。若后续版本开放 Apple 内购或官方兑换码，支付由 Apple 处理，应用通过验证过的交易判断权益，不接触银行卡资料。收费开放前会同步更新说明和界面。

数据管理与备份

你可以在应用内删除方案、规则、语音包记录和日志。模型文件如仍用于朗读，会暂时保留。模型凭据可在“语音库管理 → 模型凭据”中单独移除，即使对应模型已经删除。

删除系统声音引用包不会删除 iOS 管理的声音，也不会删除“文件”中的原件。设备备份、iCloud 文件及 Apple 交易记录由对应系统和服务管理，需分别处理。

跟踪与联系

应用不集成广告、跨应用跟踪或第三方行为分析。
