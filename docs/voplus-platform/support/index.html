旁白Plus平台版使用与支持

旁白Plus平台版正在开发，尚未公开发行。本页说明平台版的使用方式；现有内部测试版的安装渠道保持不变。

开始使用

  1. 打开“语音库管理”，选择设备已安装的系统声音，或导入兼容的语音包。
  2. 创建方案，选择主语音和可选的副语音，调整各自的语速、音量、音高和均衡器，然后保存。
  3. 在 iOS 的“设置 → 辅助功能 → 旁白 → 语音”中选择保存的旁白Plus方案。

安装和管理语音包

平台版不预装第三方声音模型。你可以从自己选择的网站下载兼容的 .vopack 文件，通过“文件”分享给旁白Plus，或在应用中选择文件。也可以打开“语音库管理 → 从链接下载语音包”，粘贴 HTTPS 链接。

下载完成后，检查包名称和版本，再确认导入。系统声音引用包需要设备已安装对应声音；模型数据包需要与应用支持的引擎兼容。若模型需要凭据，可在模型管理页添加。

语音库管理支持更新、回退和删除模型。删除模型不会更改保存的方案参数，也不会删除“文件”中的原始下载文件；使用该模型的方案需要重新安装模型或换用其他声音。删除模型会保留凭据，如需清除，可进入“语音库管理 → 模型凭据”，选择声音并确认移除。

读法如何更新

应用已支持的发音替换和数字偏好可通过 .voprules 规则包更新。在应用中导入后，需要在方案里明确选择继承包设置。原有自定义规则和方案不会被默认覆盖。

声音模型的更新使用语音包；新增引擎、解析或音频处理能力，以及需要修改应用代码的兼容性修复，则需要更新 App。
